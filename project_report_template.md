Title
Sales Performance Dashboard using Power BI
1. Introduction
This project uses data processing and business analytics techniques to explore sales performance through an interactive Power BI dashboard.
2. Problem statement
A business needs a simple way to monitor sales, profit, product performance, regional results, and payment methods. Reviewing raw rows manually makes it difficult to spot patterns quickly.
3. Objectives
Summarise sales, profit, orders, and quantity.
Compare performance across regions and categories.
Identify top products and customers.
Present results through interactive visuals and filters.
4. Tools used
Microsoft Excel or Power Query concepts for data checking
Power BI Desktop for data modelling, DAX measures, and dashboards
CSV dataset for data input
GitHub for project version control and sharing
5. Methodology
Import the CSV data.
Validate data types and clean any errors.
Create DAX measures for business KPIs.
Build visuals and slicers.
Review the visuals and summarise findings.

Insert screenshots of Overview, Product Analysis, and Customer & Payment pages here.
7. Key findings
Write 3–5 findings after building the dashboard. Example prompts:
Which region has the highest sales?
Which category contributes the most profit?
Which month has the highest sales?
Which products have high sales but lower profit?
Which payment mode is most common?
8. Conclusion
The dashboard turns sales data into a visual summary that helps users compare business performance and investigate trends using filters.
9. Limitations
The dataset is synthetic and small, so findings are for learning only and should not be treated as real business conclusions.
